AnyRAG is a production-grade, end-to-end Retrieval-Augmented Generation system designed to index and query diverse document corpora. Originally built to parse complex EU Financial Regulations, it solves the "Needle in a Haystack" problem using a two-stage hybrid retrieval funnel.

Architecture Pipeline

Query Decomposition & Caching

Multi-turn conversations are rewritten into standalone questions, decomposed, and checked against a semantic cache (cosine similarity ≥ 0.92) to bypass latency.

Stage 1: Hybrid Recall

Decomposed sub-queries are executed against a Lexical Index (BM25) and a Dense Vector Index (Qdrant). Results are seamlessly fused using Reciprocal Rank Fusion (RRF).

Stage 2: Precision Reranking

Broad candidates are reranked using an ONNX-powered FlashRank model (ms-marco-MiniLM-L-12-v2) for blazing-fast CPU inference and context reduction.

Context Reordering & Verification

Chunks are ordered using the "Lost in the Middle" technique. A secondary LLM pass ensures all generated citations map strictly to the retrieved context, penalizing hallucinations.

Observability & Tracing

The entire pipeline is instrumented with Langfuse, providing trace-level tracking of latency breakdowns, token usage, and retrieval scoring.

Engineering Decisions

Ragas Evaluation Framework

Mathematically evaluated on 32 golden queries. Iterative prompt tuning severely penalized hallucinations, achieving significant gains in baseline Context Precision and Faithfulness.

FlashRank vs PyTorch

Migrated from a PyTorch Cross-Encoder to FlashRank, dropping memory footprint from gigabytes to ~34 MB and achieving sub-100ms latency without sacrificing accuracy.

MCP Server Integration

Exposes the system as a Model Context Protocol (MCP) server, empowering AI agents like Claude Desktop and Cursor to interactively query the local knowledge base.
